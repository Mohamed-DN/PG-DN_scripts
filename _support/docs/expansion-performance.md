# Espansione delle query di prestazioni e operatività

Questa tranche aggiunge 38 query originali riscritte per gli header e le salvaguardie del repository, dichiarate per PostgreSQL 14–18. Ogni query ha limiti interpretativi in italiano e un collegamento alla documentazione ufficiale pertinente. Le query sono incluse nella matrice live PostgreSQL 14–18; esiti, hash e limiti della prova sono in [VALIDATION.md](VALIDATION.md).
