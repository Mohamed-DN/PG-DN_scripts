# Asset documentali

Directory per immagini e altri asset mantenuti manualmente nella documentazione. Preferire SVG per diagrammi statici e Mermaid nel Markdown quando il diagramma è ricostruibile dal testo.

| Asset | Uso |
|---|---|
| [banner.svg](banner.svg) | Banner illustrativo del progetto PG-DN. |

Per ogni asset binario indicare nel documento che lo usa lo scopo, la fonte/licenza e il nome significativo del file. Non salvare dump, log di produzione, screenshot con credenziali o dati personali. Gli asset generati da sorgenti riproducibili non devono essere modificati manualmente.
