# Espansione amministrazione, sicurezza e monitoraggio

Questa espansione aggiunge 36 query read-only per catalogo, privilegi e osservabilità. Ogni file contiene la propria versione minima, privilegi, limiti e costi attesi; ogni query resta in transazione `READ ONLY`, con timeout di 15 secondi per statement e 2 secondi per lock. Le query sono incluse nella matrice live PostgreSQL 14–18; esiti, hash e limiti della prova sono in [VALIDATION.md](VALIDATION.md).

Le sorgenti citate sotto `.work/upstream` sono state consultate come riferimento. Le implementazioni sono state scritte da zero a partire dai cataloghi e dalle viste documentate PostgreSQL: non sono stati copiati query, commenti o README delle raccolte senza licenza `andyatkinson/pg_scripts` e `Azmodey/pg_dba_scripts`. Non si rivendica codice upstream come proprio né si attribuisce codice di terzi a questo progetto. Per `pgx_scripts`, `pg-utils` e `postgres_dba`, i permalinks sono inclusi nei riferimenti dei file quando usati; non è stato incorporato testo o codice coperto da tali licenze, quindi non è stato necessario aggiungere un notice BSD/custom. Le attribuzioni e i testi di licenza degli snapshot già mantenuti in `_support/upstream/` restano intatti.
