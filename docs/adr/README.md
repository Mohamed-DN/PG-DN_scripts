# Architecture decision records

Gli ADR registrano decisioni architetturali che incidono su confini, compatibilità, sicurezza e flusso di lavoro del repository. Ogni documento contiene stato, contesto, decisione, conseguenze, alternative e condizioni per una revisione.

| ADR | Decisione | Stato |
|---|---|---|
| [0001 — Layout del repository](0001-repository-layout.md) | Separare strumenti curati, snapshot upstream, procedure, generatore, test e documentazione. | Accettato |

Un ADR sostituito resta nell'indice con collegamento alla decisione successiva; non cancellare la storia per aggiornare una scelta.
